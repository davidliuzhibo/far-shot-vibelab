# 千米之外 FarShot

PICO Project Swan 上的全沉浸硬核狙击游戏：荒原上的机器兵站，一支电磁狙击枪。子弹会下坠，风会吹偏，机器还在走。目标都是机器，被击毁时炸成烟和零件，没有血。

> 2026-11-05 v0.2（第一轮真机反馈后）：
> - 十二关，三章（校枪、风和提前量、千米之外）。300 米到 1000 米。
> - 用头瞄准。捏一下开镜，捏一下屏息，再捏一下开枪。瞄准镜 6 倍。
> - 只有打中机器上发光的核心才算数，观察员会报告偏了多少。
> - 第一枪之后警报倒数；打掉雷达站，剩余时间翻倍。
> - 铜、银、金奖杯，金奖杯解锁「收工烟花」。两个窗口：关卡、射表和机器。
> - 调试钩子 AutoPilot（logcat 标签 ShotTest）。

第一轮真机反馈改了这些：
- 十字线和镜框移到几十米外。之前离眼睛 0.46 米，双眼看远处目标时会看成两个，而且瞄不准。
- 十字线加粗，刻度数字放在中心下方。
- 新增绿色落点圈（默认开，可在窗口里关）：准星压住机器时，圈显示这个距离上子弹实际落在哪。把圈压到核心上开枪。
- 屏息时瞄准更稳。开镜时前景的枪台隐藏。
- 场景开局只摆一次，之后转头不会移动它。

## 测试状态

- 单元测试通过，包括不抬枪打不中、不提前量打不中。
- 模拟器：机器人走查 12 关全部三星，进程没有崩溃。
- 模拟器截图确认：只有一个十字线，绿圈落在核心上，目标名称和距离显示正确。
- **没有验证：立体视觉下十字线是否真的只有一个。** 模拟器是单眼截图，这条要在真机上确认，这也是上次的问题。
- **没有验证：用头瞄准的手感和捏合。** 机器人直接给出瞄准角度，真实头部抖动下核心是否打得中，要在真机上看。
- **没有验证：真人的难度。**

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

素材由 `tools/make_assets.sh` 生成（在外层工作区根目录运行）。安装包复制在 `apk/`。
